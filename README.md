Личный сайт Арлена Сандея. Статичный HTML/CSS/JS без сборки — открывается прямо из папки.

- `index.html` — главная
- `story.html` — история
- `constitution.html` — личная конституция и анкета «неделя в часах» (всё считается в браузере)
- `creativity.html` — стихи и книга
- `work.html` — дела
- `contact.html` — контакты

Жёлтым (`class="todo"`) отмечены места, которые ждут ответов Арлена.
